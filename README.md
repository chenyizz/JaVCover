# Ja-Video-Cover 1.0

JaVCover 是一款**离线优先**的 Windows 桌面工具，用于分析、编辑光盘/CD 封面版式：划分封面、封底、脊柱、文字区等区域，替换背景与标题，保存可复用模板，并按模板批量生成新封面。所有图片、识别与模板都在本机处理，**不会上传到云端**。

当前版本：**1.0.0**（模板文件格式 `.JaVCover` v6）。

---

## 面向使用者：直接运行（无需安装 Python）

下载 `release` 中任一形式即可：

- **`JaVCover.exe`（单文件绿色版）**：双击即用，推荐给个人用户。
- **`JaVCover-portable.zip`（目录版）**：解压后运行其中的 `JaVCover.exe`，体积解压更快、不易被杀软误报。
- **`JaVCover-Setup.exe`（安装程序）**：若发布方提供了 Inno Setup 安装包，安装后从开始菜单/桌面启动。

系统要求：Windows 10/11 64 位。无需安装 Python、Qt 或任何运行时。

> OCR 为可选功能：需自行安装 [Tesseract（UB Mannheim 版）](https://github.com/UB-Mannheim/tesseract/wiki) 并勾选 Japanese 语言数据；安装包不包含 OCR 引擎与模型。

## 功能特性

### 画布与坐标
- 打开图片 / PSD 或新建空白像素画布；滚轮以鼠标为锚点缩放，右键/中键平移。
- 上方与左侧像素标尺，可拖入水平/垂直参考线；参考线可在画布直接拖动。
- 网格、吸附（画布边缘/参考线/其它区域/网格）分别控制；网格显示在前景，缩放时自动压制过密细分线。
- 四个角 + 四个边共八个调整手柄；**拖角手柄时按住 Shift 等比缩放**。
- **对齐辅助线**：移动区域/图层时，与画布中心、区域中心、其它区域/图层的边和中心对齐会显示紫色辅助线并吸附（可在偏好设置关闭吸附）。
- **滚轮缩放可配置**：偏好设置可选“仅滚轮 / Ctrl+滚轮 / Alt+滚轮 / Shift+滚轮 / 禁用滚轮缩放”；另有“放大 / 缩小”菜单命令，快捷键（默认 Ctrl+= / Ctrl+-）可在“设置 → 偏好设置 → 快捷键”中自由修改。
- 左侧工具条与顶部“视图与吸附”工具条可在“视图”菜单中显示/隐藏；启动时始终确保显示，避免旧布局把工具条隐藏后无法找回。
- 撤销/重做（最多 100 步），撤销/重做保留当前缩放与位置。
- 可选**印刷参考线**：出血线与安全区（偏好设置里设内缩量），便于按印刷规格校对。

### 区域（版式槽位）
- 用“色块”辅助或手动画框建立 封面/封底/脊柱/文字区 等命名区域；色块候选只是启发式矩形，需要人工校对。
- 区域可**锁定/隐藏/不透明度/混合模式**，背景填充方式支持 `cover`（填充并裁剪，默认）/`contain`（完整显示）/`stretch`（拉伸填满）。
- 给区域“替换所选区背景”后图片绑定区域，随区域移动/缩放，导出按填充方式渲染。

### 图层（自由元素 / 关联区域）
- 图片或文字图层，支持系统字体、字号、填充/描边、粗斜体、逐字竖排。
- 图层可**锁定/隐藏/不透明度/混合模式**、上下移层、复制。
- **关联区域**：把图层绑定到某个区域后被限制在区域内（不越界），适合把标题艺术字放进“文字区”。
- 文字导出按设定字号在元素框内居中裁剪，**与画布预览一致**。

### 素材与 PSD 标题
- 本机素材库：保存常用 logo / PSD 标题，支持**分类子文件夹管理**、**导入文件夹**（含子文件夹）、平铺图标浏览、删除与双击放入；放入画布后嵌入项目，不依赖原路径。
- “图层 → 放置 PSD 标题素材…”把整份 PSD 复合结果栅格化为图片图层，**不要求同尺寸或透明背景**，特效完整保留。
- PSD 标题素材记住来源：在 Photoshop 改完 PSD 存回素材库后，点“刷新所选素材…”重新栅格化（位置/尺寸不变）；“重新链接素材…”指向新文件。JaVCover 不写回 PSD。
- “文件 → 打开 PSD”可将 PSD 作为新项目导入，并尽量提取可编辑 TypeLayer（复杂效果不保证还原）。

### 拖放与批量产线
- 把图片/PSD **从资源管理器拖到画布**：落在区域上自动放入并关联，落在空白处成为自由图层。
- **打开方式**：可把 `.javcover` 模板（或图片）拖到 `JAVCover.exe` 上，或用命令行 `JAVCover.exe 模板.javcover` 打开；安装程序提供可选的 `.javcover` 文件关联（按用户，免管理员），关联后双击模板即用 JAVCover 打开。
- “文件 → 批量生成封面…”：**动态添加多个目标区域**（最多等于模板区域数），各自选择素材文件夹，按**文件名（不含扩展名）对应组合**，例如 `封面/1.jpg + 脊柱/1.jpg → 1.png`。文件名模式支持 `{name}`、`{index}`、`{date}`；支持 PNG/JPEG 与 JPEG 质量。

### 界面与可靠性
- 紧凑菜单行 + 左侧单色图标工具轨；区域/参考线/图层为**三个独立可停靠面板**（可浮动、标签叠放、关闭），每个面板内可拖动分隔条调整列表高度。
- 界面与标准对话框按钮为中文（内置 Qt `zh_CN` 翻译）。
- 网格/吸附/工具模式/背景色/窗口几何/面板布局/快捷键等偏好保存在本机。
- **自动保存与崩溃恢复**：编辑后自动写入恢复文件；异常退出后下次启动可恢复。自动保存目录可在偏好设置中修改。
- 导出可选嵌入 **ICC 颜色配置文件**（.icc/.icm）。
- OCR、PSD 导入、导出、CMYK 导出、批量生成在后台线程执行并显示进度框，**可点“取消”中止**（OCR 会终止 Tesseract 子进程）。
- 网格与参考线为 1px 细线，接近 Photoshop 观感。

## 区域与图层怎么配合

- **区域（Region）= 版式槽位**：描述“封面/封底/脊柱/文字区”的矩形结构，并作为吸附参照。给区域替换背景时，图片绑定区域矩形，随区域移动/缩放，导出按 `fit` 渲染——图片略大略小都无需手动对齐，只选填充策略。
- **图层（Layer）= 自由元素**：任意位置的图片或文字，用于 logo、标题素材、装饰。可通过“关联区域”绑定到区域、被限制在区域内。

> 区域是“坑”，图层是“贴纸”；两者可叠加（区域在下、图层在上）。

| 维度 | 区域背景（替换所选区背景） | 关联图层（图层 → 关联区域） |
|---|---|---|
| 用途 | 每个槽位一张主图 | 标题艺术字、logo、角标等自由元素 |
| 摆放 | 自动填充，不可自由摆放 | 自由摆放，但被限制在区域矩形内 |
| 数量 | 每区域 1 张 | 每区域可多个 |
| 适配 | cover / contain / stretch | 手动摆放 + Shift 等比缩放 |
| 额外属性 | 不透明度、混合模式、锁定、显隐 | 不透明度、混合模式、锁定、显隐、上下移层、复制 |

## 推荐工作流（用模板做新封面）

1. **准备模板**：打开 `.JaVCover`（或导入海报后用“色块”/手动画框建立区域并命名）。保存即得到可复用模板。
2. **填版**：选中区域“替换所选区背景…”逐槽位放入主图；或把图片/PSD 直接拖到画布上的区域。
3. **加标题/装饰**：放置 PSD 标题素材或拖入图片/文字，必要时“关联区域”，再调不透明度/混合模式/层级。
4. **像素校对**：放大到 1px，配合参考线/网格/吸附与印刷参考线对齐。
5. **输出**：单张导出 PNG/JPEG、导出印刷 CMYK（TIFF/JPEG，需 Pillow），或用“批量生成封面…”按文件名组合流水线产出整套封面。
6. 需要改版时直接编辑模板；PSD 标题改完用“刷新所选素材”。

## 数据、隐私与文件

- 图片、识别、模板全部在**本机**处理；无网络上传、无遥测。
- `.JaVCover` 是带版本号的 ZIP 包：JSON 清单 + 内嵌 PNG（底图/区域背景/图片图层）。文字以内容与样式保存，导出时栅格化。**版本 1–5 模板仍可读取，当前写入版本 6。**
- 自动保存/恢复文件位于用户数据目录或你在偏好设置中指定的目录。
- 建议只使用自己有权处理的图片素材。

---

## 已知限制

- 色块建议只检测全图色彩变化，不是封面/脊柱/封底语义识别；需人工审查。
- OCR 依赖本机 Tesseract 与 `jpn` 语言数据，准确度取决于扫描与字体，必须人工校对。
- 文字支持内容与基础外观；弧形文字、字距、渐变/阴影等高级排版未提供。
- PSD 标题素材栅格化后不能在 JaVCover 内编辑文字/特效（在 Photoshop 改后用“刷新所选素材”）。
- 印刷色彩管理为可选的 ICC 配置文件嵌入；尚未做 CMYK 转换与完整色彩管理。
- 尚未实现真正的后台任务“取消”（进行中不能关闭主窗口）。

## 从源码运行（开发者）

需要 Python 3.11+：

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e .
.\.venv\Scripts\python.exe -m JaVCover.app
```

可选 PSD 支持：

```powershell
.\.venv\Scripts\python.exe -m pip install -e ".[psd]"
```

可选 CMYK 导出（Pillow）：

```powershell
.\.venv\Scripts\python.exe -m pip install -e ".[cmyk]"
```

VS Code 中打开项目根目录按 F5 使用 **JaVCover** 配置。

### 测试

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

### 打包发布（免装 Python）

```powershell
.\build.ps1                 # 单文件 + 目录版 + 便携 zip → release\
.\build.ps1 -Mode onefile   # 只要单文件
.\build.ps1 -Icon path\to\app.ico
```

- 默认会从 `src/JaVCover/icons/app-icon.svg` 自动生成多尺寸 `build\app.ico` 作为 exe 图标。
- 入口必须是 `run_JaVCover.py`，**不要**用 `src\JaVCover\app.py`（否则打包后找不到 `icons/`）。
- 安装程序：用 [Inno Setup 6](https://jrsoftware.org/isinfo.php) 编译 `installer\JaVCover.iss`（先 `.\build.ps1 -Mode onedir`）→ `release\JaVCover-Setup.exe`。

第三方 SVG 图标来自 IconPark（ByteDance，Apache-2.0），许可证见 [`src/JaVCover/icons/LICENSE-IconPark.txt`](src/JaVCover/icons/LICENSE-IconPark.txt)。
